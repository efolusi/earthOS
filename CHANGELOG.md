# Changelog

Per-package changelogs are generated by Changesets in each package directory on release. This file tracks repository-level milestones.

## Unreleased

- M0: monorepo bootstrap (pnpm + Turborepo, shared presets, CI, release workflow, OSS scaffolding)
- M1: `@earthos/core` plugin runtime, TimeEngine, WorkerPool, stores
- M2: `@earthos/gis` + `@earthos/globe` renderer and points pipeline
- M3: `@earthos/providers` framework + `@earthos/testing` contract harness
- M4: flagship plugins: satellites, earthquakes, daynight, geojson
- M5: `@earthos/ui` + flagship web app
- M6: `earthos` SDK, scaffolder, docs, examples
- M7: Meridian design system, aircraft plugin, tiled imagery, growth features (permalinks, capture, embed, eclipse, hurricanes)
- M8: Cloudflare Workers deploy (OpenNext); browser-direct data sources that survive serverless hosting (CelesTrak → TLE-API fallback, airplanes.live for aircraft)
- M9: production hardening: strict-GLSL point rendering, dense constellation shell, per-layer color identity (gold/cyan/red/violet), clamped extrapolation at extreme time rates, viewport-scoped refetch during camera motion, zoom-out cap, twilight night side, satellite/aircraft country of registry
